# Proyecto-Final-Ingenier-a-de-Software-II
## Descripcion
Proyecto académico desarrollado para la asignatura Ingeniería de Software II. Su objetivo es aplicar buenas prácticas de desarrollo, control de versiones con Git, diseño y automatización de pruebas, evaluación de calidad del software y documentación técnica, mediante la construcción de una aplicación funcional como parte del proceso de aprendizaje.

Responsable de calidad: Revisa el código, registra defectos y propone acciones de mantenimiento.
